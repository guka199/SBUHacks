# First-five-seconds hook review

ViralPilot now adds a focused editorial assessment of a video's opening alongside
the existing whole-video review, timestamped moments and thumbnail comparison.
The review covers 0 to min(5 seconds, supplied video duration). It is generated by
Gemini in the existing content-review request; no second hook-specific AI request
or new model download is needed.

## Meaning of the result

The four equally weighted criteria are attention, clarity, pacing and audio/text
support. Each has an observed explanation and a rating from 0 to 100, or null
when unobservable. The overall rating is the mean of known criterion ratings;
all unknown means a null overall rating. Missing criteria are never zero-filled.

This is an **AI editorial assessment**, not observed retention, a calibrated
viewer probability, a percentile or an estimate of views. It does not change
the frozen trained models, feature definitions, original hook field or model/
content blend. The original whole-video review remains available separately.

The research inspiration is the opening-attention question in
[Li et al., VQualA 2025 engagement challenge](https://openaccess.thecvf.com/content/ICCV2025W/VQualA/html/Li_VQualA_2025_Challenge_on_Engagement_Prediction_for_Short_Videos_Methods_ICCVW_2025_paper.html).
This implementation does not reproduce its trained models or use SnapUGC weights.
Its challenge labels are rank-normalized; importing that scale as an exact viewer
percentage would be misleading. Platform transfer/calibration is not claimed.

## Files and contract

- `api/services/gemini.py`: the opening rubric and optional structured response.
- `api/services/hooks.py`: criterion validation, score aggregation and bounded
  timestamp evidence. Missing/duplicate criteria invalidate the optional review;
  spans outside the opening, reversed spans and duplicates are dropped.
- `api/hook_schemas.py`: public HookAnalysis, HookCriterion and HookEvidence types.
- `api/routers/score.py` / `api/schemas.py`: `content.hook_analysis` in `/score`.
- `api/routers/analyses.py` / `api/analysis_schemas.py`: `hookAnalysis` in the saved
  report, shared once across platform/Shorts reviews of the same video.
- `frontend/src/lib/contracts.ts` and `web/lib/api.ts`: matching TypeScript shapes.
- `frontend/src/components/hook-review.tsx`: rating, four criteria, observed vs
  proposed opening, copy button, full-opening playback and evidence clip buttons.
- `frontend/src/components/dashboard.tsx`: integrates the review and reuses the
  existing player. Manual seeking cancels the bounded clip playback range.

Example excerpt (synthetic example, not a real audience measurement):

```json
{
  "hookAnalysis": {
    "method": "ai_review",
    "windowSeconds": 5,
    "score": 60,
    "summary": "A static introduction delays the visible payoff.",
    "opening": "A title appears before the finished result.",
    "suggestedOpening": "Show the result first, then add the title.",
    "criteria": [
      {"id":"attention","label":"First impression","score":60,"evidence":"The opening title is static."},
      {"id":"clarity","label":"Message clarity","score":80,"evidence":"The title explains the topic."},
      {"id":"pacing","label":"Opening pace","score":40,"evidence":"A pause delays the first change."},
      {"id":"audio_text","label":"Audio & text support","score":null,"evidence":"No usable audio was available to assess."}
    ],
    "evidence": [
      {"start":0,"end":2,"observation":"The title remains static.","edit":"Trim the pause and show the result."}
    ]
  }
}
```

Every evidence span satisfies 0 <= start < end <= windowSeconds. The frontend
also validates the window against the source video's reported duration. Durations
currently come from the existing browser/metadata contract, not server ffprobe.
AI timestamps are bounded editorial references, not frame-accurate measurements.

## Setup and fallback behavior

Use the existing root `GEMINI_API_KEY`; optional `GEMINI_MODEL` and
`GEMINI_THINKING` settings are unchanged. Start the API and frontend using
`docs/frontend-backend.md`. Upload a new video and open Platform overview or
Video insights. Existing saved reports are not automatically re-analyzed.

Images/caption-only requests never get a video opening review. Missing or failed
Gemini keeps model-only scoring. If only the optional hook object is malformed,
the valid whole-video review is retained and the opening review is unavailable
with a retry warning. Old saved reports load with a null hookAnalysis field and
an explanatory UI state. No demo ratings are passed off as real AI results.
The proposed opening is a suggestion, clearly separated from observed content;
the app does not claim to edit the uploaded file or prove a performance lift.
