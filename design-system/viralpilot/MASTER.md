# ViralPilot design system

The user's approved red/yellow identity is authoritative. Preserve its typography, scene, composition, main copy, automatic loop and story order during refinement. UI UX Pro Max was initialized using its official CLI; downloaded tooling is ignored.

## Applied guidance

- UI UX Pro Max: contrasting action hierarchy, numeric chart labels, explicit demo states, keyboard focus, breakpoint-specific controls.
- Taste/Impeccable: preserve the approved physical/type identity, inspect real content/states in browser, improve placement without unnecessary replacements or label rewrites.
- Design DNA: source-derived tokens, expressive creative personality and physical/glass/motion effects remain three separate dimensions in DNA.json.
- Three.js Skills / official Fiber docs: color-managed PBR, compressed local GLBs, shared keys, capped DPR, owned-resource cleanup, demand rendering and measured-corner DOM projection. React19/Fiber9/Drei10/Three0.180 compatibility retained.
- GSAP Skills: scoped contexts, disjoint timeline ownership, explicit reversible states, scrub smoothing, easing, transforms, visibility pause and cleanup.
- LottieFiles Motion Design: staging, anticipation, stagger, follow-through and settle phases implemented in GSAP; no extra Lottie runtime.
- Genjutsu: supported official installer and lightweight existing-stack guidance; no unsupported runtime features or agent swarm.

## Motion and performance

Three platform window shells; five browser tabs and six bounded notifications. Independent16-second loop, not scroll-driven notifications. Product story: problem, Meet ViralPilot/glass, analysis, comparison, optimization, unified report. No unbounded spawning. Scroll reverses; loop resumes at opening. Outdoor180-second sine motion/depth parallax stays subtle. Phone/no-WebGL exterior is static capture while HTML animates. Reduced motion removes looping/pinning.
